# Clasptek Prep Portal V2 — Engineering Governance Package

This package converts the approved architecture into an implementation-governance handbook.

## Files

- `Clasptek_Prep_Portal_V2_Engineering_Implementation_Governance_Guide.md` — Complete Engineering Implementation Governance Guide.
- `Clasptek_Prep_Portal_V2_Module_Ownership.csv` — Single-accountable-team module ownership register.
- `Clasptek_Prep_Portal_V2_EDR_Register.csv` — Engineering Decision Record register.
- `Clasptek_Prep_Portal_V2_Engineering_Roadmap.csv` — Engineering implementation roadmap.
- `Clasptek_Prep_Portal_V2_Quality_Gates.csv` — Production quality-gate register.
- `Clasptek_Prep_Portal_V2_PR_Checklist.md` — Reusable pull-request compliance checklist.

## Authority

The handbook does not redesign Phase 0 or Phase 0.5. It governs how engineering teams implement the approved architecture.
