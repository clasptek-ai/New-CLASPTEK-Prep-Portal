# Sprint 2.8 — Regression Detection Report

## 1. Objective

Tracks and detects score, latency, cost, and agreement regressions.

---

## 2. Regression Gateways

- **Agreement Degradation:** Triggers warn/critical alarms when agreement rate drops.
- **Calibration Drift:** Monitors if AI confidence aligns with actual scoring accuracy.
- **False Positives/Negatives:** Checks error rate changes on low-scoring submissions.
