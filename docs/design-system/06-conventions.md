# Design System Conventions & Naming Rules

**Status**: Canonical Standard

- **PascalCase Exports**: All React components use PascalCase (`Button`, `StatCard`, `QuestionNavigator`).
- **Barrel Export**: All components MUST be re-exported through `src/shared/ui/index.ts`.
- **CSS Utility Tokens**: Class names follow standard prefix conventions (`c-button`, `c-card`).
