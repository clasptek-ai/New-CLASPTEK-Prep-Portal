# Accessibility & WCAG 2.1 AA Standards

**Status**: Canonical Standard

- **Contrast Ratio**: 4.5:1 minimum for standard body copy, 3:1 for large display headers.
- **Focus Rings**: Mandatory visible focus outline (`outline: 2px solid #38bdf8; outline-offset: 2px`).
- **Keyboard Trapping**: Modals and drawers must trap focus and release focus on `Escape`.
- **Screen Reader Labels**: `aria-label` required for icon-only buttons, `aria-live="polite"` for dynamic notifications.
