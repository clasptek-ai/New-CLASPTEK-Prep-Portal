# Design System Principles & Philosophy

**Status**: Canonical Standard

1. **Clarity Over Decoration**: Non-functional gradient flourishes are prohibited.
2. **Hierarchy Over Clutter**: Establish strong visual ordering via typographic scale, contrast, and elevation.
3. **Whitespace Over Density**: Predictable spatial margins (`var(--spacing-16)`, `var(--spacing-24)`).
4. **Consistency Over Creativity**: Identical component contracts across all workspaces.
5. **Accessibility Over Aesthetics**: WCAG 2.1 AA minimum contrast and keyboard focus trapping.
6. **Speed Over Complexity**: Micro-interactions finish in `150ms - 200ms`.
