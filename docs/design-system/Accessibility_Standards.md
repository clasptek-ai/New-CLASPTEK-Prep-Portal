# Accessibility Standards (WCAG 2.2 AA)

## Guidelines

- Color contrast ratio minimum: 4.5:1 for standard text, 3:1 for large text.
- Keyboard Navigation: All interactive elements (`Button`, `Input`, `Switch`, `Select`) support full keyboard focus and visible focus rings.
- ARIA Labels: Screen readers announce states (`aria-checked`, `aria-expanded`, `role="alert"`).
