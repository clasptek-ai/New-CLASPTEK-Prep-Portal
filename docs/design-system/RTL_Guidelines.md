# RTL & Logical CSS Guidelines

## Forbidden Physical Directions

- Do NOT use: `margin-left`, `margin-right`, `padding-left`, `padding-right`, `float: left`.

## Required Logical Properties

- Use: `margin-inline-start`, `margin-inline-end`, `padding-inline-start`, `padding-inline-end`, `text-align: start`.
- Tailwind Equivalents: `ms-`, `me-`, `ps-`, `pe-`, `text-start`.
