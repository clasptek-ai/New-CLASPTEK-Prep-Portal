# Design Token Specification

## Canonical Source

`/packages/design-tokens/tokens.json`

## Token Structure

- **Colors**: Primary, Secondary, Success, Warning, Danger, Info (scale 50–900).
- **Semantic Aliases**: `button.primary.background`, `card.background`, `exam.correct`, `exam.incorrect`.
- **Spacing**: 0, 2, 4, 8, 12, 16, 20, 24, 32, 40, 48, 64, 80px.
- **Motion**: `hover` (150ms), `click` (100ms), `modal` (250ms), `drawer` (300ms), `skeleton` (1200ms).
