# Package Manifest: @clasptek/domain-exam-product

## Purpose

Declares the Domain Model primitives (ExamProduct Aggregate Root, ExamProductVersion, OfficialExamStructure, OfficialExamComponent, ExamDeliveryConfiguration, and ExamRegionalVariant Entities, Value Objects, State transitions, Specifications, Policies, and Core Events) for exam product boundaries.

- **Depends On**: `@clasptek/kernel`

- **Consumes**: Kernel Entity and ValueObject base types
- **Business Domain**: Exam Product Bounded Context
