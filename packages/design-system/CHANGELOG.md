# Changelog - @clasptek/design-system

## [3.0.0] - 2026-07-20

### Added

- Initial release of Clasptek Design System (CDS) v1.0.
- Single source of truth design tokens package (`@clasptek/design-tokens`).
- Light / Dark / System `ThemeProvider` engine with `localStorage` persistence.
- Motion provider with standardized transition timing tokens.
- Icon registry supporting Lucide icons.
- Layout primitives (`Stack`, `Inline`, `Grid`, `Container`, `Section`, `Page`, `Spacer`).
- Integrated Form system (`Form`, `FormField`, `FormLabel`, `FormError`, `FormHint`, `FieldGroup`, `Input`, `Textarea`, `Checkbox`, `Switch`, `Select`).
- Foundation components with WCAG 2.2 AA metadata (`Button`, `Card`, `Skeleton`, `EmptyState`, `DataTable`, `QuestionCard`).
- Email primitives & email templates.
- PDF report layout standard.
