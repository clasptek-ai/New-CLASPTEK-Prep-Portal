Scoring Calibration

Understanding the IELTS 9.0 Band Scale

Scores are standardized against the Common European Framework of Reference (CEFR) for higher education admission across Oxford, Cambridge, Harvard, and top immigration tribunals.

Band 8.5 – 9.0 CEFR C2
Expert User

Fully operational command: fluent, accurate, and completely appropriate with sophisticated academic synthesis.

Doctoral & Medical Fellowships
Band 7.0 – 8.0 CEFR C1
Very Good User

Operational command with occasional unsystematic inaccuracies. Handles complex detailed argumentation smoothly.

Ivy League / Russell Group Standard
Band 6.0 – 6.5 CEFR B2
Competent User

Generally effective command despite some misunderstandings. Can use and understand reasonably complex language.

Standard Undergraduate Admissions
Band 5.0 – 5.5 CEFR B1
Modest User

Partial command with frequent mistakes. Copes with overall meaning in familiar contexts; needs targeted foundation.
